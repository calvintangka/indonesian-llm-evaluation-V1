# Indonesian–English LLM Evaluation

An independent, single-annotator exploratory study of code-switching across six language models, using ten prompts and a five-dimension rubric.

**[Read the corrected evaluation report](README_evaluation_report.md)** | [Scoring workbook](Indonesian_LLM_Evaluation_Scoring_Sheet.xlsx)

The report explains the scoring, corrected arithmetic, and limitations. The complete original prompts and responses are not currently available in this repository; model-interface provenance also needs further verification. Historical figures have not been revalidated.
